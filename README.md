# PO Receipt Monitoring Dashboard — GitHub Starter

This is a responsive, self-contained HTML demo inspired by Pantone 15-5217 TCX Blue Turquoise.

## Demo limitations
- All PO records and chart graphics are illustrative sample data.
- The app is not connected to Odoo.
- The Run Data button intentionally does not fetch real data.
- Some navigation items are placeholders for later implementation.
- The digital color is an on-screen approximation; displays and browsers may vary.

## Test locally
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Create a new repository named `po-receipt-monitoring-dashboard`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Open the URL displayed on the Pages settings screen after deployment completes.

## Before using real Odoo data
Use a protected backend for Odoo access. Never put passwords, API keys, session tokens, or other credentials in browser JavaScript or a public GitHub repository. Implement read-only access, pagination, error handling, and data validation before connecting production data.
